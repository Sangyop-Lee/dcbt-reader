# Gaiji (characters outside the standard fonts)

Used by DCBT Reader to display characters that the Mac's fonts cannot draw.
All files come from CBETA's public repositories (https://github.com/cbeta-org):

- `CBETASupplement.ttf` — cbeta-fonts @ cc6961a (2026-10-21). A subset of 全宋體 FSung
  covering CBETA's rare characters that are in Unicode. Free for non-profit and
  personal research use; see the cbeta-fonts README.
- `glyphs.bin` / `glyphs.idx` — the GIF glyph images from gaiji-CB @ e402e97 (2026-11-02),
  sd-gif @ 45afba1 (Siddham) and rj-gif @ f68a8b9 (Rañjanā), packed into one file.
  Each line of `glyphs.idx` is: id, byte offset, byte length.
