# Dictionaries

Put your dictionaries here. DCBT Reader looks up selections of up to four
characters in them.

- StarDict: the three files (`.ifo`, `.idx`, and `.dict` or `.dict.dz`), or the
  archive you downloaded, unopened (`.tar.bz2`, `.tbz`, `.trz`, `.tar.gz`,
  `.zip`, `.7z`, `.bz2`).
- Babylon: a `.bgl` file.

Choose which ones to use in DCBT Reader ▸ Dictionary Settings, and press Rescan
there after adding a file.

The app is distributed without dictionaries. See section 2 of the README in
the folder above for the formats and for how to look for them.
