# SLR files

Optional. Put CBReader "limited search" range files (`.slr`) here to restrict
searches to a group of texts. Each file lists text numbers such as `T33n1698`
under a `[SutraSingle]` or `[BuleiSingle]` section, one per line as `0=T33n1698`.
The groups appear in the "SLR group" menu at the left of the window.
